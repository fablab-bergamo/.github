# 🌟 Chi Siamo

FabLab Bergamo APS è un'associazione di promozione sociale e laboratorio di fabbricazione digitale situato a Bergamo. Facciamo parte della rete globale FabLab, fornendo accesso a strumenti di fabbricazione digitale, promuovendo l'innovazione e costruendo una comunità di maker, studenti, professionisti e appassionati.
La Nostra Missione: Democratizzare l'accesso alla tecnologia e permettere alle persone di trasformare le loro idee in realtà attraverso l'apprendimento pratico, la collaborazione e la condivisione open source.

## 🛠️ Le Nostre Attrezzature
Siamo dotati di strumenti professionali in diverse discipline:

* 🖨️ Reparto Stampa 3D: Stampanti FDM e a resina
* ⚙️ Reparto Macchine e Utensili: Taglio laser, CNC, utensili tradizionali
* ⚡ Reparto Elettronica: Stazioni di saldatura, strumenti di misura, schede di sviluppo, componenti elettronici comuni
* 🎨 Reparto Grafica: Macchine da cucire, plotter da taglio, postazioni grafiche


# 💻 Progetti Open Source in Evidenza
## 🔐 Fab-O-matic
Sistema di Controllo Accessi RFID per Macchine
Una soluzione completa basata su ESP32 per gestire l'accesso alle macchine del FabLab tramite tessere RFID. Include architettura C++ moderna, progetti hardware e integrazione backend.
Stack Tecnologico: C++, ESP32, Arduino Framework, MQTT
⭐ Perfetto per: FabLab, makerspace, laboratori condivisi

## 🎮 Squid Game Doll
Robot "Un, Due, Tre, Stella!" Basato su AI
Un progetto robotico che combina Raspberry Pi 5 con rilevamento e tracciamento dei giocatori basato su intelligenza artificiale, più bambola animata controllata da ESP32.
Stack Tecnologico: Python, Raspberry Pi 5, ESP32, Computer Vision
⭐ Perfetto per: Appassionati di AI, studenti di robotica, intrattenimento per eventi

## ☢️ Contatore Geiger
Sistema Avanzato di Rilevamento Radiazioni
Kit contatore Geiger potenziato con integrazione ESP32, con elaborazione dati sofisticata, medie mobili e display visivi.
Stack Tecnologico: Python, ESP32, MicroPython
⭐ Perfetto per: Scopi educativi, monitoraggio ambientale

## 🐍 Corso Python 2026
Materiali Didattici Interattivi per Python
Corso completo di programmazione Python con slide e notebook Colab per l'apprendimento pratico.
Stack Tecnologico: Jupyter Notebooks, Python
Stato: Attivo - Corso in Corso
⭐ Perfetto per: Principianti, studenti, autodidatti
